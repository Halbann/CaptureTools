# Changelog

## 1.2.0

- Added integration with Scatterer to support Scatterer's TAA/SMAA and sunlight colour modulation in main cam and multi cam outputs.


## 1.1.0

- Added an option to draw the flight UI to the main camera output. This method draws the flight UI exactly as it looks on your screen, so 3D icons/labels won't line up exactly when using smoothing.

- Added an option to only record audio. This can be used alongside an external recorder and the decimator script to record lag-free footage with sound that includes the flight UI, IMGUI (most mod windows) and external post processing effects like reshade. A sync marker will flash on screen when you start recording in audio only mode to show you where to place the audio when editing.

- Removed some unnecessary logging.
